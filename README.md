# ⚽ Бот Мониторинга Билетов Ticketon: ФК Кайрат — ФК Ордабасы

Автоматический мониторинг наличия 2 парных мест (в одном ряду) на матч Кайрат — Ордабасы на Центральном Стадионе Алматы.

## 🚀 Как запустить через Docker (Рекомендуемый способ на 1 день)

### На любом VDS/сервере или ПК с Docker:

```bash
# 1. Склонировать / скопировать папку проекта на сервер
cd kairat_ordabasy

# 2. Запустить контейнер в фоновом режиме:
docker compose up -d --build
```

### Посмотреть логи работы бота:
```bash
docker compose logs -f ticketon_bot
```

---

## 🐍 Локальный запуск без Docker (на текущем ПК)

```bash
pip install -r requirements.txt
python bot.py
```

## 📱 Использование в Telegram:
1. Зайди в бот `@omarigato_notification_bot`
2. Отправь команду `/start`
3. Бот подпишет тебя на мгновенные уведомления о появлении **2 соседних мест в одном ряду**!
